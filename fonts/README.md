# Fonts

Self-hosted subset files used on Soffit Web, so the heading and label typefaces load from this site instead of Google Fonts.

- **Fraunces** — [SIL Open Font License 1.1](https://scripts.sil.org/OFL), by Undercase Type. [Google Fonts specimen](https://fonts.google.com/specimen/Fraunces)
- **IBM Plex Mono** — [SIL Open Font License 1.1](https://scripts.sil.org/OFL), by IBM. [Google Fonts specimen](https://fonts.google.com/specimen/IBM+Plex+Mono)

The `.woff2` files are the latin, latin-extended, Vietnamese, Cyrillic and symbols subsets served by Google Fonts for the weights used on the site (Fraunces 460 and 620, IBM Plex Mono 400 and 500).
