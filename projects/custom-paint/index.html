Brief

Photo Markup Studio is a browser tool for marking up a photograph: paste an image, draw on it, then copy or download the result, or send it to a job pack.

What was done

The studio screen — tools, colour, line settings, and a canvas — rebuilt as a static layout so the interface can be read without opening the app. The controls on this page do not draw.
